# PayRun | Codebase

This folder contains the source code for the PayRun application, organized into frontend and backend components.

## Structure

- **/frontend**: React (TypeScript) + Vite + MUI v5 application.
- **/backend**: Database schema (Supabase SQL) and compliance logic.

## Key Features

1. **One-Click Compliance Exports**: PF ECR and PT Return generation.
2. **WhatsApp Distribution**: Automated payslip delivery via Cloud API.
3. **Smart Onboarding**: Magic Link flow for employee KYC.
4. **Auditability**: Complete history of payroll changes.

## Getting Started

1. **Backend**: Run the SQL in `backend/setup.sql` on Supabase.
2. **Frontend**:
   - `cd frontend`
   - `npm install`
   - `npm run dev`
