# PayRun | Codebase

This folder contains the source code for the PayRun application, split into frontend and backend components.

## Structure

- **/frontend**: React (TypeScript) + Vite + MUI v5 application.
- **/backend**: Database schema (Supabase SQL) and compliance logic.

## Getting Started

1. **Backend**: Apply the SQL script in `backend/setup.sql` to your Supabase project.
2. **Frontend**:
   - `cd frontend`
   - `npm install`
   - `npm run dev`
